# Shopify public snapshot

Generated by `python3 tools/snapshot.py` from https://sala.company's public storefront. Don't edit by hand.

- `meta.json`: store metadata (`/meta.json`)
- `products.json`: all products with variants, images, `body_text`, video trailers and the local media paths
- `collections.json`: collections with `product_handles`
- `articles.json` + `articles/*.md`: blog posts (full HTML from the Atom feed, plus a plain-text version)
- `policies/*.md`: the five bilingual policies (Ministry of Commerce details are here)
- `pages/home.html`: the home page HTML, kept for layout reference
- `media/`: product, article and theme images, and the MP4 trailers
